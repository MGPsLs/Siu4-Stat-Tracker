This is a personal project for a basketball match stat tracking.

The website automatically retrieve current permament players for the team Siu4 and allows user to manually add stand-in players to track their stats as well.

To stat track simply click on the button for the stat made by a player, and the website well automatically add respective stats to the player stat table.
For example, if player 1 hits a field goal, click +FGM and the web well automatically mark player 1 for 2 points, 1 field goal made and 1 field goal attempted
